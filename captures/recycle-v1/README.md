# First version of the recycling demo (kept on purpose)

These results come from the first version of `demos/recycle.py`, run on 30 September 2026.

That version offered five options (the five street bins), and its grey option said
"broken glass, ceramics, toys". The city does not say that: its Waste Finder sends those to a Green Point.
So Jev answered "grey" with high confidence, and it was wrong because our options were wrong.

The current version has six options and its results are in `captures/recycle/`.
